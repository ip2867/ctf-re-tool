## 5. 模型接入现状（卡点，含精确报错）

用户约束 `[用户提供]`：**不用 dpv4.1f（cbcn/deepseek-v4.1-flash）；只用 ZCode 内的两个 Start Plan（GLM-5.3-Flash 300M / GLM-5.3 200M）；一个额度用完自动换下一个。**

三条路的实测结论（全部 `[已验证]` 2026-10-26）：

1. **直连 Start Plan 端点** ✗
   端点/Key 取自 `C:\Users\Administrator\.zcode\v2\config.json` → `provider["builtin:bigmodel-start-plan"]`（baseURL `https://zcode.z.ai/api/v1/zcode-plan/anthropic`，key 为 JWT）。
   ```
   POST {base}/v1/messages → 405 {"code":3012,"msg":"request has been blocked due to unusual activity."}
   ```
   已排除：UA（`ZCode/2.0.0` 等 5 种）、X-Session-Id/X-App-Id 头、系统代理 7890、Electron `net.fetch`（Chromium TLS 栈）——全部同样 405。
   根因 `[推断]`：桌面端每次模型请求携带渲染层动态计算的 "provider runtime headers"（日志证据：`~\.zcode\v2\logs\<当日>.log` 搜 `runtime headers`；头值被脱敏）。复刻 = 绕过反滥用机制，**不做**。
2. **10router 的 `zcode-free/glm-5.3-flash`** ✗（本机今天不可用）
   `/v1/models` 能看到，调用 → `502 ECONNREFUSED 127.0.0.1:47860`。该前缀需要 **CreditDaddy 桌面版"额度网关"**（默认口 47860；10router changelog 原文：enable the gateway switch under "ZCode → Interface settings" in CreditDaddy desktop）。
   本机**未安装** CreditDaddy（已查 Programs / AppData / 进程 / 注册表 Uninstall / 全盘浅搜，均无）。
   → **可执行选项 A（需用户同意）**：安装 CreditDaddy → 开 ZCode 网关开关 → 验证 `netstat -ano | findstr :47860` 有监听 → 把 config.json 的 model/fastModel 改 `zcode-free/glm-5.3-flash`（若网关同时暴露 glm-5.3 则一并配）。
3. **open.bigmodel.cn 的 Coding Plan key** ✗
   `~\.zcode\v2\credentials.json` 解密（AES-256-GCM，密钥=sha256(`zcode-credential-fallback:{platform}:{homedir}:{username}`)，未设 `ZCODE_CREDENTIAL_SECRET` 时）取到的 key：`429 code 1113 余额不足或无可用资源包`——走的是开放平台余额，不是 Start Plan 额度。

**结论**：等用户装 CreditDaddy（选项 A）或放宽模型约束。不要在这上面反复试——已有 6 种变体全败。

## 8. 环境与坑（实测）

- **cmd 里 `node -e "...中文..."` 会静默失败/参数被吃**（报 `'错误' 不是内部或外部命令`、`;` 被粘进文件名）→ 一律写临时 `.js` 脚本再 `node xxx.js`，用完删。
- 控制台 GBK：PowerShell 管道里中文乱码（内容无损，仅显示）；要看清用重定向到文件再读。
- 杀外部工具用 `powershell Stop-Process -Name ida -Force`（taskkill 对挂满插件的 IDA 无效）。
- 杀 Electron 只按 PID/当前实例；**绝不 `Stop-Process -Name node` 全杀**（会杀 10router，见 §7）。
- DevTools 随机端口偶发 bind 失败（TIME_WAIT；electron.log 可见 `Cannot start http server for devtools`），驱动换会话即恢复。
- Defender：`E:\ctf\pratice\ai` 下新落盘 EXE 可能被持锁/隔离（工具已有 blocked-by-av 分类 + 本次 2.5s 重试）。
- 启动工具（手动）：`npm start` 或 `启动.bat`（纯 ASCII，勿加中文）。
